A program that writes one original one-line joke about office life to `/output/entry.txt` and prints it to stdout. The joke is a single line of 85 characters, with the punchline landing on the last word: a badge that opens every door in the building except the one that leads to a raise.

## Run it

```sh
node main.ts
```
